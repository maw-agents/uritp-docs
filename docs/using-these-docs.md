# Using these docs

A short orientation so you can find things fast and trust what you find.

## Reading

**Search covers everything.** The search box at the top indexes every page, including tables and venue notes. Searching a piece of gear, a door, or a catwalk number is usually faster than navigating.

**The right-hand rail is the current page's outline.** It tracks as you scroll. On narrow screens it collapses into the page header.

**Every page is printable.** Use your browser's print or save-as-PDF. Navigation and chrome are stripped automatically and the content reflows to paper. Print a venue page and take it into a production meeting if that is easier.

## Trusting what you read

Measurements and specifications marked [To be confirmed]{.tbc} have not been verified since the most recent renovation. **Do not put a to-be-confirmed number in your paperwork.** Measure on site or ask production management.

Everything else has been confirmed by someone who checked. Each page carries a revision date; if a page has gone a season without an update and you are relying on it heavily, ask.

## Contributing

You do not need to know git.

1. Click the **pencil icon** at the top right of any page.
2. Edit the text. It is plain markdown: `#` for a heading, `-` for a bullet, `**bold**`.
3. Describe your change and propose it.

Production management reviews and merges. Once merged, the live page updates in about ninety seconds.

If you would rather not touch the repository at all, send the correction to production management in whatever form is easiest. A note that says "the west crossover does not exist" is more useful than a perfectly formatted edit you never send.

## Access

The site is open to anyone with the link. **Editing is not.** Write access is limited, which is why the information here can be treated as authoritative rather than crowd-sourced.

Box folders linked from these pages follow your University of Rochester account. If a folder will not open for you, that is a permissions issue, not a broken link.
