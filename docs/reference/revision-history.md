## How versioning works here

There is no v1 / v2 / v3. Every commit is a version, every change is diffable against the one before it, and the live site always reflects the current state of `main`.

This is deliberate. Numbered document versions distributed as files create the problem where three people are building off three different revisions and nobody knows it. A single live URL cannot drift that way.

If you need a frozen snapshot for an archive or a contract, print the page to PDF and date it. Just do not distribute that PDF as the source of truth.
